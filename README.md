# special-lamp
Personal STL-like library for research purpose, featuring the following implementations :
 - Various sorting algorithms
 - Allocator(Currently broken)
 - Assert
 - BST
 - Deque
 - Heap
 - List
 - Math
 - CRC32 hash
 - Murmur3 hash
 - Queue
 - Random
 - Stack
 - String
 - Unordered_map(unstable for some types)
 - Vector
